# ior Android

## Настройки и сохранение VPN — 0.2.11 (23 октября 2026)

Добавлены управление журналом (20 МиБ / 7 дней по умолчанию), экономия
мобильного трафика и автоматическая загрузка каталога приложений. При потере
сети служба сохраняет TUN и ожидает восстановления транспорта. Поддерживается
системный Always-on; блокировка соединений без VPN включается пользователем
в настройках Android. Подробности: `docs/settings-and-continuity-20261022.md`.
APK: `android-output/settings-20261022/ior-android-arm64.apk`.

## Reality RAW и AWG — 0.2.10 (20 октября 2026)

Reality RAW повторно использует положительный DNS-ответ VPN-сервера до истечения
TTL; одновременные соединения разделяют один запрос. Кэш принадлежит коннектору
и сбрасывается при смене его физической сети. Бинарные TCP-пакеты больше не
ожидают HTTP-заголовок только из-за заглавной первой буквы. AWG получает
передачу управления после каждых 64 прочитанных TUN-пакетов. Исправлена потеря
уже прочитанных данных при закрытии приложением своей отправляющей половины TCP.

APK: `android-output/reality-awg-20261020/ior-android-arm64.apk`.
Рабочая версия 0.2.9 сохранена в `android-output/dns-hysteria-20261020/`;
резервная копия перед изменениями: `.local/backups/reality-awg-20261020/`.
Обоснование, границы ускорения и проверка на телефоне:
`docs/android-reality-awg-20261020.md`.

## DNS и UDP Hysteria2 — 0.2.9 (20 октября 2026)

Обращение к виртуальному DNS `172.19.0.2:853` получает TCP RST без ожидания
прокси; внешний DNS-over-TLS и обычный DNS не меняются. Hysteria2 уступает
выполнение после 64 входящих датаграмм, чтобы готовые получатели успевали
вычитывать очереди. Лимит каждой очереди сохранён: 1024 сообщения.
Добавлены отдельные счётчики UDP-потоков и исправлено закрытие простаивающих
UDP-потоков при включённой периодической диагностике.

APK: `android-output/dns-hysteria-20261020/ior-android-arm64.apk`.
Очистка генерируемых файлов: `scripts/Clean-ProjectBuildCache.ps1` показывает
план, с `-Apply` выполняет его. Сохраняются исходники, конечные native-бинарники,
выпуски, резервные копии, ключи и SDK/NDK. Первая сборка после очистки дольше.

## VLESS — кандидат 0.2.6 (18 октября 2026)

VLESS + TLS: RAW/TCP, WebSocket, HTTPUpgrade, gRPC (gun/multi), XHTTP.
VLESS + Reality: RAW/TCP, gRPC и XHTTP. WS/HTTPUpgrade с Reality отклоняются.
Vision поддерживается только с Reality + RAW. XHTTP использует HTTP/2,
режимы auto/stream-one/stream-up/packet-up и отдельный downloadSettings;
HTTP/3 и неописанные дополнительные параметры не поддерживаются.

Импорт сохраняет SNI (sni/peer/serverName), Host/authority, path, serviceName,
ALPN, заголовки, режим gRPC и параметры XHTTP download. Подписки VLESS также
сохраняют fingerprint, ALPN и multi-mode. Неизвестные режимы gRPC и настройки
XHTTP download отклоняются. Проверка сертификата TLS остаётся обязательной.

Отдельный APK-кандидат: `android-output/vless-resume-20261018/ior-android-arm64.apk`.
Предыдущий `distandroid/ior-android-arm64.apk` сохранён. Подробности проверок,
резервной копии и ручного прогона: `docs/vless-transports-resume-20261018.md`.
Проверки на реальном телефоне ещё не выполнены.

Первый APK: Android 10+ (API 29), arm64-v8a. Kotlin, локальный мобильный интерфейс
в WebView и собственное Rust-ядро `libior_android.so` через JNI. Нативный Rust AWG,
Hysteria2 и VLESS Reality; Go, sing-box и Xray в APK отсутствуют.

## Сборка

Один раз выполнить `scripts/Setup-Android.ps1`, затем открыть `android.bat` либо
запустить `scripts/Build-Android.ps1`. Результат заменяется в
`android-output/current/ior-android-arm64.apk`; `dist.bat` остаётся Windows-сборкой.
Для целевых проверок использовать `scripts/Test-Android.ps1`.

Для выдачи на телефон запустить `distandroid.bat`: он заново собирает Rust-ядро,
интерфейс и подписанный release APK в `distandroid/ior-android-arm64.apk`.
При повторном запуске обновляется тот же файл; ключ подписи сохраняется.

Закреплены Gradle 8.13, AGP 8.13.2, Kotlin 2.2.21, compile/target SDK 36,
NDK 27.2.12479018, Java 17. Библиотека выровнена на страницы 16 КиБ.
SDK/NDK/Java и Gradle-зависимости находятся в `.local/android-tools`.
Постоянный ключ подписи и его пароль находятся в `.local/android-signing`;
они исключены из Git и автоматической очистки. Сохраните их для будущих обновлений APK.

## Что реализовано

- Настоящий Android VpnService, разрешение Android, уведомление и отключение.
  TUN-дескриптор дублируется Rust и закрывается при остановке. Внешние сокеты
  защищаются `protect()` и связываются с физической сетью; ошибка защиты не обходится.
- Общий пакетный путь AWG с Windows: независимый приём, прямой TCP/UDP и бюджет
  64 МиБ. Прочие протоколы используют существующий TUN-мост ior-core.
- Конфигурации, нативная проверка параметров, импорт файлов/ссылок и QR-камера.
- Маршруты ior/Clash: DOMAIN, DOMAIN-SUFFIX, DOMAIN-KEYWORD, IP-CIDR, IP-CIDR6,
  MATCH; DIRECT/PROXY/REJECT. Неподдерживаемые правила отклоняются.
- Список установленных приложений, значки и взаимоисключающие списки VPN/исключений.
  Пустое правило VPN выключено. Изменения применяются после переподключения.
- HTTPS-подписки, ручное обновление, включаемое автообновление примерно раз в
  шесть часов. При отказе остаются прежние серверы и время успешного обновления.
  HWID выключен по умолчанию; отдельное согласие на HTTPS-origin, без передачи
  идентификатора на неразрешённый origin при редиректе.
- Шифрование состояния ключом Android Keystore, отключённое системное резервирование.
  Собственная копия без секретов либо AES-GCM/PBKDF2-копия с паролем. Восстановление
  подтверждается и выполняется при выключенном VPN; HWID-согласия не переносятся.
- Реальные счётчики трафика, журнал состояния службы, RTT до сервера по клику.
  Для AWG/Hysteria применяется системный ICMP при его доступности, для Reality —
  физическое TCP-подключение. Отказ измерения показывается как недоступность.

## Ограничения первого выпуска

Не входят обычный WireGuard, остальные протоколы, Happ/sing-box-маршруты и Google
Play. Hysteria2 с obfs/insecure не принимается. Данные расхода,
лимита и срока выводятся только из заголовков подписки. Обновите System WebView,
если устройство не поддерживает защищённый канал WebMessageListener.

Сборка и локальные проверки не подтверждают подключение и скорость на телефоне.
ADB-устройство при разработке не было подключено. Первый реальный прогон:
импорт личного тестового профиля, разрешение VPN, три протокола последовательно,
сайт/видео, выбор приложений, смена Wi-Fi/мобильной сети, выключенный экран,
QR, резервная копия и отключение. Для AWG не используйте один peer одновременно
на компьютере и телефоне.

Windows dist и быстрый принятый контроль `6d24f334603b` не заменялись.
