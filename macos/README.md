# ior macOS — предварительная оболочка

Это ещё не рабочий VPN-клиент. Включён существующий интерфейс в режиме просмотра и собранное ядро. Не реализованы macOS TUN, защищённый помощник, Keychain, хранение подписок и восстановление сети. Подключение недоступно; права администратора оболочка не запрашивает.

Сборка через GitHub Actions пока требует первого успешного запуска на macOS. Без этой проверки не распространять как готовый VPN. Приложение использует тестовую ad-hoc подпись, без Developer ID и notarization. Gatekeeper может запретить запуск; не отключайте защиту системы целиком.

Apple Silicon: arm64. Intel: x64. Минимальная целевая система: macOS 13.

## Сборка из Windows

Установить GitHub CLI и выполнить `gh auth login`. Добавить исходники и workflow в репозиторий, сохранив секреты вне Git. Закоммитить и отправить нужную ветку; workflow должен быть доступен в основной ветке. Запустить `dist.bat`. Неотправленные изменения блокируют общий выпуск, чтобы Windows и Mac не собирались из разных исходников.

Повторное скачивание: `powershell -File scripts/Build-MacOSRemote.ps1 -RunId NUMBER`. Пакеты сохраняются в dist/macos-arm64 и dist/macos-x64. Релизы не публикуются автоматически.

Windows-сборка продолжает работать при недоступном GitHub. Строгий режим всех платформ: `dist.bat -RequireMacOS`. Только Windows: `dist.bat -WindowsOnly`. Файлы приложения Mac пересылайте внутри ZIP: распаковка и повторная упаковка на Windows может потерять права доступа и символьные ссылки.
