# Интерфейс функций приложения

Карта построена по текущим командам WebUiHost.cs. Ни одна команда C# не вызывается. `native-feature-map.json` содержит полный перечень.

Локальная ссылка/QR использует сохранённую исходную ссылку, а не мобильный контейнер приложения. Импорт YAML/Happ сохраняет исходный текст без имитации его разбора. Резервная копия имеет отдельный тип `ior-visual-prototype`. Системная диагностика и обновления неизвестны. Удалённый игровой режим не добавлен.

Шаблон диалога обновляется через согласование DOM: одно открытие, без повторных enter-анимаций при изменении вкладки или формы. Контекстное меню вызывается ПКМ, Shift+F10, ContextMenu и «⋯».

Проверки: feature-base-verification.json, feature-model-verification.json, feature-dom-verification.json. LinkeDOM проверяет дерево, события и сохранение узлов, но не пиксели, размеры окна или визуальную плавность. Зависимость только для проверки размещена в test-runtime и не включена в HTML. Браузерные проверки file:// остаются заблокированы политикой.
