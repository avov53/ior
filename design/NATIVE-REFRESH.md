# Основной интерфейс ior

`npm run build` создаёт `design/index.html`. Проект C# копирует его в `webui/index.html`; WebView2 открывает страницу через существующий `https://app.ior`.

Общие компоненты, стили и диалоги находятся в `prototypes/desktop-refresh`. Основная сборка добавляет `scripts/native-refresh.js`: реальные данные приходят только через WebView2. Хранилище визуального прототипа не импортируется. В браузере нативные действия показывают недоступность; тестовые результаты не подставляются.

Настройки интерфейса — сворачивание навигации и уменьшение движения — сохраняются отдельно в `ior-ui-preferences`. Серверы, профили, маршруты, язык и тема сохраняются приложением. Доступны чёрная и белая темы; старые сохранённые палитры отображаются как соответствующая светлая или тёмная. Редактор сохраняет неизвестные поля конфигурации. Существующие маршруты ior редактируются как полный JSON, Clash — как исходный YAML; Happ показывает исходные ссылки для чтения и позволяет менять название. Выбор действия по умолчанию доступен только при создании маршрута ior.

Копирование ссылки и окно QR запрашивают `server.share` с `format: protocol`: стандартные vless/vmess/hysteria2/trojan/ss/socks ссылки формируются действующим `MobileShare`. QR кодирует ту же строку с белым полем в четыре модуля. Неподдерживаемые для Happ протоколы возвращают понятную ошибку вместо внутреннего QR ior. Экспорт файла сохраняет полный формат ior отдельно. `server.latency.refresh` принудительно измеряет указанный сервер без смены выбора и объединяет параллельные запросы одного адреса. Флаги встроены из flag-icons вместе с MIT-лицензией, внешние запросы для них не нужны. Экспорт маршрута независим от обновления состояния страницы и использует исходный формат.

Фоновый снимок состояния не пересоздаёт DOM, если данные видимой страницы не изменились; скрытая страница не перерисовывается. После возвращения в окно запрашивается актуальное состояние. Периодические снимки не создаются при свёрнутом окне. Размытие крупных поверхностей отключено; переключатели используют отдельные контрастные цвета дорожки и бегунка.

Экспорт конфигурации доступен только для WireGuard/AmneziaWG через `server.export` и создаёт файл `.conf` с Interface/Peer и параметрами AWG. У подписок и ссылочных протоколов этот пункт скрыт. Маршруты экспортируются отдельно в исходный YAML/ссылку маршрута. Профили используют `connectionProfile.export`/`connectionProfile.import` и JSON с Type `ior-connection-profile`, Version 1: настройки профиля, его конфигурации, маршрут и адрес подписки. Импорт создаёт новые идентификаторы и восстанавливает связи без переключения текущего подключения и загрузки подписки; разрешения HWID не переносятся. Создание копии добавляет её в активный профиль, чтобы она не скрывалась фильтром доступных серверов.

Проверка: `node scripts/verify-native-refresh.mjs` запускает DOM и подставной WebView2 без VPN/системных операций. Она не проверяет пиксели и геометрию окна. Визуальная проверка заблокирована ранее полученным запретом браузера на локальные страницы и обходные способы загрузки.

Предыдущая активная страница и исходники сохранены в `checkpoints/before-native-refresh-20261010.zip`. Старые исходники и восстановительные скрипты перемещены в `checkpoints/inactive-ui-20261010` и исключены из активной сборки. Прототип остаётся отдельным способом просмотра тех же компонентов.
