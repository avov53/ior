# Маршрутизация: Windows 1.2.9 / Android 0.2.15 (17)

Общий переключатель сохраняется независимо от сервера. Выключение применяет пустой набор пользовательских правил с финальным PROXY; исключения работы VPN остаются. Системный none удаляется при миграции. Для новой установки переключатель включён, без маршрута используется VPN для всего обычного трафика.

Маршруты подписок добавляются автоматически без согласия. При новом подключении выбирается маршрут подписки сервера; без такого маршрута применяется пустой набор правил. Ручной выбор применяется через безопасное переподключение. Фоновая загрузка не перезапускает текущий туннель. Название и URL подписки показаны над её маршрутом. Одинаковые маршруты разных подписок хранятся отдельно.

Миграция сохраняет пользовательские маршруты, выбранный none преобразует в выключенный переключатель. Отложенные маршруты восстанавливаются; ошибки восстановления не должны сбрасывать всё хранилище. Старые поля согласия оставлены для чтения резервных копий, интерфейс согласия убран.

Локальные проверки: 383 теста .NET; 55 JUnit Android; DOM/bridge проверки обеих платформ, отсутствие окна согласия, переключатель и команды. Проверены контрольные суммы прежних ZIP/APK: без изменений. Родное ядро не менялось. Резервная копия: .local/backups/routing-toggle-20261103.

Нужна проверка на телефоне и реальной Windows-сети: переключение при действующем VPN, сетевой сбой при применении и возврат прежнего маршрута, потеря сети, две реальные подписки с разными правилами. Автотесты не доказывают сетевую готовность устройства. Релиз GitHub не публиковался.
