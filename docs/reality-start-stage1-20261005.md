## Изменения

- VLESS Reality в экспериментальном режиме использует существующий быстрый путь проверки TUN, ранее применявшийся к Hysteria2. Реальный HTTPS через PROXY остаётся обязательным; DNS и UDP проверяются параллельно с пределом 2 секунды. Сетевые проверки адресов, DNS/маршрутов, владение адаптером и откат сохранены. Этот предел не является пределом всей операции запуска.
- Во время TLS-handshake RecordSocket допускает чтение нескольких TLS-записей за раз. До отправки VLESS-заголовка он возвращается к чтению одной записи, необходимому для корректного перехода Vision на внутренний TLS. Криптография и проверка подлинности Reality не менялись. TCP_NODELAY уже был включён.
- В диагностику добавлены REALITY_WORKER_READY и REALITY_CLIENT_HELLO_READY с durationMs; REALITY_TLS_COMPLETE содержит durationMs, readCalls и readWaitUs. Счётчики числовые, без ключей и содержимого запросов.
- Предупреждение sing-box сбрасывается перед новым запуском и при выборе сервера/ядра. Сообщения помечены поколением процесса; сообщения прежних процессов и предыдущей попытки запуска отбрасываются. Предупреждение Reality принимается только для работающего sing-box с Reality-профилем. Новая ошибка действующего соединения сохраняется.
- Локальная ошибка интерфейса очищается при смене сервера/ядра, новом подключении и успешном состоянии. Запоздавший отказ операции не возвращает старую локальную ошибку поверх успешного соединения.

UDP/443 для стандартного `xtls-rprx-vision` остаётся запрещённым согласно существующей политике. В коде есть отдельный вариант `xtls-rprx-vision-udp443`; профиль автоматически на него не переключался. HTTP/3 сайта, XUDP и транспорт XHTTP — разные механизмы. XHTTP/H3 в этот пакет не добавлялись; MTU, параметры профиля, DNS и сервер не менялись. TCP-буферы и congestion control без подтверждённого ограничения также не менялись.

## Проверки

- 246 .NET-тестов прошли. Новый тест проверяет фильтрацию устаревшего предупреждения по поколению процесса, ядру и протоколу. Существующие тесты readiness сохраняют обязательность HTTPS и ограничение необязательных проб.
- 85 тестов ior-core, 3 интеграционных теста и 1 тест netstack прошли (89 всего). Новый тест проверяет чтение TLS во время handshake и восстановление границ записи перед Vision.
- Сборки интерфейса, release Rust и self-contained Windows publish прошли.
- Живая проверка сохранённого Reality-профиля через Proxy прошла: HTTPS и SOCKS UDP. Процесс ядра завершён, порт освобождён. Пользовательское состояние и сеть Windows не менялись.
