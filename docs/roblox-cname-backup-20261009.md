# Roblox / CDN: выбор полного DNS-ответа

9 октября 2026. Работающее соединение Hysteria2 не отключалось.

Воспроизведён отказ публичного WebP со скриншота: Windows DNS для tr.rbxcdn.com вернул SERVFAIL, HTTP CONNECT по имени завершился 502. Прямые DNS/TCP и SOCKS UDP-пробы через существующий Hysteria2 установили: Google 8.8.8.8 возвращает полную цепочку CNAME и A-адреса; Яндекс 77.88.8.8 возвращает только CNAME trns1.rbxcdn.com, для которого A не получен. По IP из полного ответа Google тот же файл, с сохранённым TLS-именем, вернул HTTP 200, 48944 байта за 0,588561 секунды. Это проверка HTTP, не отображения в браузере.

Общий DNS-путь TUN теперь при положительном A/AAAA ответе с незавершённым CNAME и без терминального SOA сразу проверяет резервный настроенный resolver. Ответ не переписывается. При отказе всех резервов сохраняется исходный корректный ответ. Такой промежуточный ответ не удерживается в общем кеше при наличии резервов. Обычный NODATA, NXDOMAIN, SOA отрицательного ответа, HTTPS/SVCB и одиночный resolver сохраняют прежнюю обработку. В трассировке добавлен безопасный код TUN_DNS_CNAME_INCOMPLETE.

Целевые тесты: tun_dns 15, native_router 12, dns_exchange 4, AWG 16 (7 расширенных стендов не запускались), tun 2; группы пересекаются. Проверены повторный запрос через кеш, успешный резерв, сохранение CNAME при отказе резерва, терминальный NODATA/SOA и сервисные записи. Rust release и Windows 10/11 publish успешны. В сборке остаются предупреждения неиспользуемого кода и NU1900 о недоступности данных аудита NuGet; ошибок сборки нет.

Изменение действует для всех протоколов, использующих общий TUN DNS. MTU, профильные DNS, TCP-окна и движок AWG не менялись. Контрольные архивы stable-fast-control.zip и seek-fast-control-overlay.zip проверены и сохранены. dist не запускался и не изменялся.

Кандидаты: verification-publish/awg-current/windows-10 и windows-11. Для короткого журнала только Roblox можно после закрытия текущего ior запустить Start-RobloxDiagnostics.cmd (Windows 11) либо передать windows-10. Требуется повторно проверить конкретное превью, аватары сайта и игры; успешная загрузка всех картинок пока не подтверждена. Живая проверка Windows 10 и последовательное AWG Rust/Go сравнение не выполнялись.
