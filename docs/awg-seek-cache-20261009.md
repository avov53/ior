# AWG: кандидат для перемотки, сохранённый быстрый контроль — 2026-10-09

Пользователь подтвердил быстрый запуск 4K, сайтов и приложений, стабильное 2× на
предыдущем кандидате. Он сохранён независимо от новых сборок в
verification-publish/awg-current/stable-fast-control.zip (полный Windows 11 пакет
и точные отличия Windows 10), с отдельным stable-fast-control.validation.json.
Контрольное ядро SHA256: efbf6c928fbadb0bffec38949c4a61cfafb13be556b9079f50a56a65fcdc6ef3.
Проверены архивное ядро и отличия двух платформ: sing-box.exe и ior.win10.
Архив не перезаписывается и не удаляется при очистке этой итерации.

## Изменения кандидата

- Исправлено разделение кешей DNS-ответов AWG транспорта и TUN. Они используют
  один кеш; PROXY и DIRECT, resolver, порт, A/AAAA, TCP/UDP и байты параметров
  запроса сохраняют отдельные ключи. 8.8.8.8 и 8.8.8.8:53 означают один resolver.
  Ответ сохраняет порядок адресов; при возврате обновляются ID и оставшийся TTL.
  Запросы с другими флагами/EDNS не подменяются совпадающим только именем ответом.
- Общие пределы: 512 ответов, 1 МиБ, равны прежней сумме двух отдельных кешей.
  Обычный WireGuard и остальные протоколы получают прежние отдельные кеши.
- При совпадающих параметрах уже полученный ответ исключает дополнительное
  обращение к resolver. На промахе сохраняются существующая резервная проба и
  сетевое разрешение. Одновременные промахи двух путей ещё могут дать два запроса;
  единая очередь ожидания в эту итерацию не добавлялась.
- Устранена подтверждённая двойная обёртка диагностики TCP приложения: она
  дублировала BrokenPipe/закрытие и учёт байтов. Добавлены lastReceivedAgoMs,
  lastSentAgoMs и afterFirstSendMs для сопоставления пауз и первых ответов.
  Запросы/TLS-содержимое не анализируются и не журналируются.
- В отмене дефекта не выявлено: Drop отменяет рабочую задачу и освобождает
  владельца очереди/бюджета; half-close сохраняет чтение. Поведение не менялось.
- Rust по умолчанию, окно fallback 512 КиБ, бюджет 64 МиБ, маршрутизация,
  MTU/DNS/ключи/обфускация сохранены. Принудительного закрытия по ожиданию чтения нет.

## Как сравнить и откатиться

Кандидат: awg-current/windows-11 или windows-10, весь каталог. Для контроля
распаковать stable-fast-control.zip в отдельное место и запускать ior.exe из
корня. На Windows 10 скопировать содержимое windows-10-overrides поверх корня
распакованного контроля; Windows 11 эти отличия не применяет.
Это самостоятельный пакет, он не требует файлов нового кандидата. Состояние
пользователя в APPDATA не откатывается и архивом не заменяется.
При явно заданном внешнем пути ior-core проверить, что запускается ядро контроля,
а не кандидат: префикс SHA256 контрольного ядра efbf6c928fba.

По пять одинаковых перемоток одного видео 4K, затем запуск и длительное 2×,
изображения и Discord. Одинаковые сервер/DNS/профиль маршрутизации; после смены
пакета переподключать VPN. При ухудшении использовать сохранённый контроль.
AWG_DNS_SHARED_CACHE_HIT показывает исключённый повторный запрос; его отсутствие
не ошибка — параметры могут отличаться или DNS может идти вне ior.
Ускорение перемотки остаётся неподтверждённым до сравнения.

В awg-current остаются пакеты, защищённый контроль, короткий отчёт и контрольные
суммы; прежний небольшой control-overlay.zip сохранён. Промежуточные файлы и
проверенные сборочные кеши этой работы очищены. dist и исторические пакеты сохранены.
