# AWG: Rust по умолчанию и автоматическая маршрутизация — 2026-10-09

Rust назначен основным после сообщения пользователя о более быстрой загрузке
и перемотке 4K по сравнению с Go. Это пользовательское наблюдение, не универсальный
результат измерений. AWG остаётся экспериментальным протоколом ior-core + TUN.
Старые настройки один раз мигрируют на Rust; последующий ручной выбор Go сохраняется.

## Поведение

- Отдельного переключателя FullProxy в настройках больше нет. Старое значение
  сохраняется для совместимости состояния, но не переопределяет выбранный маршрут.
- Без выбранного маршрута или с пустым профилем: MATCH → PROXY. При наличии
  правил сохраняются их порядок и DIRECT/REJECT, завершающий маршрут AWG — PROXY.
  Сохранённый профиль не переписывается. Пропавший выбранный профиль даёт ошибку.
- Свежие DNS-наблюдения позволяют выбрать пакетный PROXY до первого SYN/датаграммы.
  Для общего CDN-адреса все сохранённые имена должны выбирать PROXY. Конфликт,
  переполнение наблюдений, истёкший TTL или необходимость определения имени
  сохраняют прежний путь через стек. Выбранный путь закреплён на всё соединение.
- Это маршрутизация по известным DNS-именам, а не проверка SNI каждого пакетного
  соединения. Зашифрованный DNS/кеш браузера может оставлять имя неизвестным;
  одинаковая скорость с полным режимом для всех таких случаев не гарантирована.
- Неподдерживаемое семейство отклоняется до принятия нового соединения только
  при определённом PROXY. DIRECT IPv6 сохраняется. Скрытого DIRECT нет.
- Убраны промежуточная копия криптографического вывода и копирование обычного
  TUN-пакета перед пакетной отправкой. MTU, DNS, обфускация, ключи и бюджеты прежние.

## Проверки

- 36 целевых .NET-тестов: миграция, ручной Go, пустой маршрут, старый FullProxy,
  DIRECT/REJECT, неизменность профилей и поведение остальных протоколов.
- 13 целевых Rust-тестов: параметры/handshake/rekey/MAC/replay/cookies,
  checksum/NAT, маршрутизация/TTL/неоднозначность DNS и закрепление TCP-пути.
- Настоящий HTTP/3: Rust AWG → официальный Go, локальный стенд RTT 100 мс,
  фиксированные потери 0,5%; завершился успешно, очереди/бюджет без переполнений.
  В этой итерации системный Wintun/маршруты не менялись.
- CPU-сравнение, 10 чередующихся образцов по 4096 пакетов: медиана для payload
  32 байта 2868 → 2788 мкс; 1200 байт 4393 → 4294 мкс. p95 3035 → 2833 и
  4681 → 4497 мкс. Сравнивает наличие промежуточной копии, не сеть и не браузер.
- React, release Rust и self-contained Windows 10/11 publish прошли.
  Windows 10 вживую и ускорение сайтов с правилами в этой итерации не проверены.
  Firefox не автоматизировался. Логи успешных проверок и сборочные кеши очищены;
  результаты/контрольные суммы сохранены в validation.json и cleanup.json.

## Ручная проверка

Использовать полный каталог awg-current/windows-11 или windows-10. После
обновления отключить/подключить AWG. В настройках Rust — основной, маршрутизация —
автоматическая. Сравнить на одном пакете отсутствие выбранных правил и профиль
с российскими DIRECT-сайтами: одинаковое 4K-видео, запуск, перемотка, длительное
2×, Discord и изображения. По пять повторов; фиксировать Buffer Health, остановки
и Dropped Frames. Для PROXY с известным DNS ждать AWG_PACKET_ADMITTED с
nameSource=dns_observation; fallback означает сохранение проверки имени/стека.

Дополнительное ускорение сайтов и равенство скорости двух сценариев остаются
неподтверждёнными до этого сравнения. При регрессии сохранить журнал и вернуться
на Go вручную; произвольного перезапуска соединений по ожиданию чтения нет.
