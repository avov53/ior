# Windows 10 — тестовая 1.2.6: Xray и автоочистка

В присланном журнале Xray создал адаптер, но приложение остановило соединение
из-за ошибки диагностического кода события. Измерения теперь используют постоянный
код `XRAY_TUN_PROBE_MEASURED`, а название этапа — отдельное безопасное поле.
Ошибка необязательного измерения не должна останавливать VPN. Сам Xray не заменялся.

Монитор AG теперь сообщает только о повторном появлении подтверждённых правил AG.
Собственное правило ior и неизвестные правила не выдаются за возвращение AG.
Временное отключение AG и восстановление после остановки/сбоя сохранены.

## Хранение

Только на Windows 10 генерируемые конфиги находятся в защищённой пользовательской
папке `%TEMP%\ior-runtime-<идентификатор папки данных>`, а не в корне AppData.
Используются фиксированные имена двух файлов, которые перезаписываются.
Папка и файлы ограничены доступом текущего пользователя.

При запуске, после завершения подключения и раз в час ior удаляет известные
неактивные конфиги, DNS-копии и диагностические JSON старше 24 часов.
Когда приложение закрыто, очистка продолжится при следующем запуске.
Старые известные конфиги в AppData очищаются по тому же правилу.

Настройки/подписки, чужие файлы и основной журнал не удаляются этой очисткой.
Для основного журнала сохраняется выбранная пользователем политика хранения.
При работающем ядре сохраняются его конфиги и отчёты запуска. При незавершённом
восстановлении сети сохраняются DNS-бэкапы и диагностические данные, независимо
от возраста. Активные журналы восстановления вообще не входят в список очистки.
Они и связанные копии могут оставаться дольше суток — это необходимо для восстановления.
Пути-ссылки не обходятся при очистке.

## Проверка

421 тест .NET прошёл. Новые проверки используют настоящий обработчик диагностики
после имитированного успешного обнаружения адаптера, проверяют собственные/неизвестные
правила DNS и очистку до/после суток, защиту активного конфига и аварийного журнала.
Реальные DNS и маршруты локального компьютера в этих тестах не менялись.

Распаковать полный новый Windows 10 ZIP в отдельную папку, закрыть старый ior.
Проверить Xray TUN с Hysteria2/VLESS Reality, затем ior-core. После отключения
проверить возвращение правил AG. Если запуск не удался — прислать журнал;
если появилась `win10-tun-failure.json`, просмотреть её перед передачей.
Настоящий запуск Xray и поведение NRPT на проблемном Windows 10 требуют ручной проверки.

Windows 11, Android, dist и предыдущие пакеты не заменялись. Публикации GitHub нет.
Резервная копия затронутых исходников: `.local/backups/win10-cleanup-20261106`.
