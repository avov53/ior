# Hysteria2 Salamander — Android 0.2.17 (19), Windows 1.2.11

Причина: Android ProfileCodec запрещал любой obfs, Windows CoreRuntimeContract тоже отклонял obfs, а Rust-коннектор не передавал пароль в уже существующую Salamander-реализацию vendor-hysteria.

Добавлены obfs/obfsPassword в приватный контракт. Поддерживается salamander, пароль 4–4096 UTF-8 байт; неизвестные режимы и пароль без режима отклоняются. Коннектор передаёт пароль библиотеке. Проверка сертификата включена, insecure=true не разрешён. Существующие профили без obfs продолжают работать.

Android: импорт URI, передача параметров из YAML/JSON (включая вложенный obfs), отдельная ошибка проверки TLS. Ошибка разбора одной ссылки в текстовой подписке больше не отменяет импорт остальных; предупреждение содержит только количество записей, без ссылок и паролей. Если все записи пропущены, старый рабочий список сохраняется.

Проверено: 57 Android JUnit; 385 .NET; 150 Rust tests passed, 12 ignored. Проверены ложные и слишком короткие obfs-параметры, импорт смешанной подписки, передача в нативный контракт. Новый APK содержит другую нативную библиотеку по сравнению с 0.2.16; подпись проверена сборщиком. Windows ядро сверено с новым release-бинарником (da0aeba36215...). Реальное подключение к серверу пользователя и телефон не проверены. Личные ссылки и ключи не добавлены в тесты или документацию.

APK: android-output/salamander-20261104/ior-android-arm64.apk. Windows: windows-output/salamander-20261104 и dist/windows-10, dist/windows-11. Предыдущие сборки сохранены; backup .local/backups/hy2-salamander-20261104. Для телефона установить APK поверх прежней версии и повторно обновить подписку.
