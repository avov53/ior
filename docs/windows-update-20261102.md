# Обновление Windows — версия 1.2.8

При запуске ior проверяет стабильный релиз `avov53/ior`. Предложение с кнопками «Обновить» и «Позже» появляется только для более новой версии с подходящим ZIP Windows 10/11. Отказ сохраняется на время работы приложения; повторный запуск позволяет предложить этот релиз снова. Ручная проверка находится в настройках, раздел «Дополнительно».

Согласие запускает загрузку, подготовку, штатную остановку VPN и восстановление сети. После подтверждения готовности скрытого помощника приложение закрывается. Помощник ждёт завершения процесса и устанавливает пакет в прежнюю папку, затем запускает ior. Отдельного подтверждения установки не требуется. После обновления автоматическое подключение VPN пропускается.

Проверяются версии EXE и DLL, соответствие тега релиза, комплектность и маркер пакета Windows. Файлы перед заменой резервируются; результат копирования проверяется по SHA-256. При ошибке заменённые файлы восстанавливаются, новые файлы удаляются, прежнее приложение запускается с сообщением об ошибке. При неполном восстановлении резервные файлы остаются во временной папке с указанием её адреса. Пользовательские настройки и журналы не являются файлами устанавливаемого пакета.

Скрипт встроен в приложение и запускается штатным Windows PowerShell. Учтены UTF-8 с BOM, пробелы и кириллица в путях, запрет ссылок в путях установки, проверка границ временной папки и результата записи. Ошибка удаления временных файлов после успешной установки не запускает откат уже установленной версии.

## Публикация

Подготовлены локальные архивы `ior-windows-10.zip` и `ior-windows-11.zip` в `windows-output/update-20261102`. Для релиза 1.2.8 следует загрузить оба архива в GitHub Release с тегом `v1.2.8`; следующие релизы должны аналогично содержать полные пакеты с соответствующей версией EXE/DLL и маркером Windows. В этой задаче релиз GitHub не публиковался.

Старые версии содержат прежний механизм обновления. Новое окно и защищённая замена файлов работают после установки 1.2.8. Для первого перехода можно установить полную папку новой сборки вручную.

## Проверки и ограничения

382 теста .NET прошли, включая выбор релизов и наличие корректно закодированного встроенного помощника. Проверки интерфейса покрывают автоматическое предложение, отсутствие дубликатов, отказ, согласие, прогресс загрузки и отсутствие предложения без подходящего ZIP.

Файловые проверки установщика выполнялись на отдельных папках: успешная установка, занятый файл и откат, пробелы/кириллица, сохранность пользовательских файлов. Дополнительно проверяется копирование полного пакета и контрольные суммы всех его файлов. В этих проверках запуск приложения отключён параметром `-NoLaunch`.

Полный живой цикл «скачать новый релиз GitHub → остановить пользовательский VPN → перезапустить новое приложение» не выполнялся: рабочая установка и системная сеть не обновлялись тестами. Предыдущая сборка сохранена; копии исходников находятся в `.local/backups/update-20261102`.
