# AWG / Hysteria2 TUN: проверка загрузки 2026-10-04

## Изменения

- Новый принадлежащий ior Wintun получает готовые (Preferred) адреса до установки DNS и маршрутов. DAD отключается только на этом новом point-to-point адаптере, не на физических интерфейсах Windows.
- DNS и UDP-пробы проверяют домен, направленный через PROXY; ответ сопоставляется с событиями маршрута и DNS ядра. HTTPS по-прежнему обязателен, DNS/UDP имеют отдельные результаты.
- Фактическая способность AWG обслуживать IPv6 учитывается независимо от флага контракта. Локального IPv4 и AllowedIPs `::/0` недостаточно для внутреннего IPv6. DIRECT не ограничивается этим условием.
- ICMP/ICMPv6-отказ UDP содержит исходную длину и корректную контрольную сумму цитируемого пакета; цитата ограничена по размеру. Это исправляет распознавание отказа потока, но не гарантирует поведения конкретного браузера.
- DNS-наблюдения, включая SVCB/HTTPS address hints, связываются с последующим потоком событием DNS_FLOW_LINKED. Ответ DNS не переписывается; неоднозначные общие адреса не связываются с произвольным доменом.

## Методика и ограничения

40 чередующихся подключений: 10 для каждой пары протокол/вариант, одинаковые DNS и правила, один компьютер Windows 11 и существующие серверы. Baseline использует прежний Rust-бинарник и прежнюю подготовку адресов; current — новый бинарник и готовые адреса. Общая процедура проб и подготовленный сетевой исполнитель одинаковы. У каждого цикла проверяется восстановление сети; отдельно выполняются нормальное завершение и падение ядра.

HTTP-пробы измеряют первый байт тела и полное тело ответа, не отображение страницы, Telegram Updating или начало воспроизведения видео. Discord проверяется WebSocket Hello без авторизации. Firefox-автоматизация остановлена инструментом: проверка URL-политики для текущего Windows-браузера не поддерживается. Обход ограничения не применялся.

Настройки серверов, MTU, AWG-обфускация и параметры QUIC не менялись. Секреты и чувствительные URL в этот отчёт не включаются. Загрузка через зашифрованный браузерный DNS, сон/смена Wi-Fi и полноценное отображение приложений требуют отдельной проверки; результаты HTTP нельзя считать их заменой.
