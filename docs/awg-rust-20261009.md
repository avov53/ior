# AWG Rust: экспериментальный кандидат, 9 октября 2026

## Что реализовано

- В FullProxy новая неподдерживаемая семья адресов отклоняется до приёма TCP
  в старый стек: SYN получает корректный RST/ACK, UDP — ICMPv6. Отказ ограничен
  32 ответами/с и учитывается отдельно как AWG_PACKET_FAMILY_REJECTED.
  Rules сохраняет прежнюю маршрутизацию. DNS/HTTPS hints, IPv6 Windows,
  параметры сервера, ключи, MTU и обфускация не перенастраиваются.
- Новый Rust-движок работает внутри ior-core без дочернего процесса/pipe.
  Изолированная локальная копия BoringTun 0.7.1, BSD-3-Clause, в vendor-awg;
  обычный WireGuard продолжает использовать неизменённую registry-зависимость.
  Эталон AWG — amneziawg-go v3.1.20260828, MIT. Лицензии включены в пакеты.
- Поддержаны Jc/Jmin/Jmax, S1–S4, H1–H4/диапазоны, I1–I5 с выражениями
  b/t/r/rc/rd/d/ds/dz, HeaderProtectionKey, ContentPaddingAddition,
  RekeyAfterTime/RekeyTimeout/RejectAfterTime/KeepaliveTimeout/MaxHandshakeAttempts,
  RandomTrailers и DisableCookies. Неизвестные/повреждённые параметры отвергаются.
  Суммарные пред-handshake junk/I-пакеты ограничены 1 МиБ; большие неподдерживаемые
  настройки отвергаются, а не изменяются молча.
- Пользовательские типы handshake устанавливаются до MAC1/MAC2, входящие байты
  не переписываются перед проверкой MAC. Header protection использует библиотечный
  ChaCha20; Noise/AEAD/replay остаются на основе BoringTun/ring. Это не самостоятельный
  аудит безопасности и не основание считать новый движок production-проверенным.
- Исправлена обнаруженная на нагрузке потеря пакетов в Rust: для прямого пути
  драйвер ждёт места в ограниченной входной очереди. UDP-буферы ограничены 2 МиБ
  на направление. Go и остальные протоколы эту новую ветку не используют.
- Настройки → Дополнительно → «Движок AmneziaWG»: Go / Rust. По умолчанию Go,
  в том числе для старого состояния. Оба движка используют одинаковый пакетный
  путь и настройку маршрутизации. Ошибка Rust не скрывается переключением на Go.

## Проверки и ограничения

- Целевой Rust-прогон: 10 тестов, включая защищённый handshake, MAC, cookie/MAC2,
  replay, повреждения, rekey, параметры/выражения и ранний IPv6-отказ. Четыре
  opt-in теста пропущены в обычном прогоне; необходимые стенды запускались отдельно.
- 22 целевых .NET-теста: состояние, параметры, оба движка и контракт режимов.
  Сборка React, release Rust и self-contained Windows 10/11 publish прошли.
- Rust ↔ официальный Go: TCP/UDP с header protection, дополнительным padding и
  random trailers, закрытие/отмена пакетного пути. Только локальные синтетические ключи.
- TCP Windows через Wintun: IPv4 и IPv6, по 64 МиБ с целостностью, маленький
  запрос одновременно с большой передачей, параллельная загрузка, отмена и
  запрос после паузы. Один сценарий RTT 100 мс, фиксированные потери 0,5%.
- Первый нагрузочный прогон выявил переполнение очереди и таймаут. После
  исправления повтор завершился с кодом 0 и штатным откатом. Общая длительность
  сценария: IPv4 39,390 с, IPv6 173,537 с; включены дополнительная передача,
  параллельные/маленькие запросы, пауза и отмена. Это НЕ сравнение скорости
  Go/Rust и НЕ измерение YouTube. IPv6-сценарий заметно медленнее; Rust основным
  не назначен, ускорение не подтверждено.
- После стенда не обнаружены его процессы, адаптер и маршруты. Живое пользовательское
  подключение и Windows 10 в этой итерации не проверялись. Firefox не автоматизировался.

## Как сравнить

Запускать полный каталог awg-current/windows-11 или windows-10. Выбрать
ior-core + TUN, экспериментальное тестирование, AWG FullProxy. Сначала Go,
затем Rust; после каждой смены движка отключить/подключить VPN. Сохранить один
сервер, конфиг, DNS, MTU, видео и кодек. На телефоне тот же конфиг одновременно
не включать. Проверить длительное 4K/2×, перемотку, Discord и изображения;
сохранить время остановок, Buffer Health, Dropped Frames и журнал.

На Rust ждать AWG_RUST_ENGINE_READY и AWG_HANDSHAKE_AUTHENTICATED; pipe-счётчики
для этого клиента нулевые. Отказы семьи и fallback различаются. IPv6-only сайт
без IPv4 через IPv4-only профиль не станет доступным от смены языка.

Go остаётся контролем и вариантом возврата. Rust можно сделать основным только
после совместимости и отсутствия ухудшения на реальном сравнении. Мгновенную
загрузку, минимальный пинг и стабильное 4K/2× заранее не обещаем.

В awg-current остаются только готовые Windows-пакеты, этот краткий отчёт и
контрольные суммы. Временные рабочие файлы/успешные подробные журналы и проверенные
сборочные кеши этой работы очищаются после упаковки. dist, исторические контрольные
пакеты, исходники, зависимости и пользовательские данные сохраняются.
