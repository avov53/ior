# AWG: независимый приём при задержанной отправке

10 октября 2026. Исправлен локально воспроизведённый дефект Rust AWG: ожидание socket.send в общем цикле препятствовало приёму и обслуживанию таймеров при backpressure физического UDP-сокета. Связь этого дефекта с конкретным зависанием YouTube ещё не подтверждена.

Обычная отправка использует try_send без дополнительной копии. При WouldBlock сохраняется ограниченная FIFO (1024 пакета), включённая в существующий общий бюджет 64 МиБ. Пока FIFO не опустела, новые пакеты приложения остаются под backpressure, а приём и таймеры обслуживаются. Зашифрованные пакеты не переупорядочиваются; переполнение явно учитывается. Отмена освобождает сохранённые пакеты. Сервер, ключи, DNS Roblox, маршруты, MTU и TCP-окно не изменялись. Go не изменялся.

Два регрессионных теста: прежняя последовательность send/recv блокируется при незавершённой отправке, новый select принимает ответ; FIFO, ошибка приёма и освобождение бюджета проверены. На окончательном ядре локальный стенд против официального Go: 64 МиБ с проверкой содержимого, восемь параллельных маленьких запросов, отмена и новая загрузка прошли (RTT 100 мс, потери 0,5%). HTTP/3: два ответа по 1 МиБ через Rust и отдельно Go прошли. Эти проверки используют синтетические ключи и не меняют системные маршруты.

Исправлена доставка transport/nameSource в resources.jsonl: раньше поля выводились в журнал, но отбрасывались при записи отчёта. Четыре .NET-проверки прошли. Полные ссылки, cookies и ключи не сохраняются.

Текущее пользовательское AWG (ядро 7701e009fa30) не отключалось. Две публичные HTTPS-загрузки Cloudflare по 64 МиБ через текущую системную маршрутизацию дали HTTP 200, HTTP/1.1, 16,3954 и 19,699609 с (32,75/27,25 Мбит/с). Маленький запрос одновременно со второй загрузкой завершился за 347 мс. Это измерение текущей сборки, не сравнение кандидата и не доказательство скорости YouTube. Маршрут конкретного публичного запроса не был независимо зафиксирован. В текущем run 8f724f4c5e75454c9c531dd4ef2a0acc наблюдалось 260 queueDroppedPackets; агрегированный счётчик не определяет конкретную очередь или видеопоток.

Пара Rust/Go на пользовательском сервере не запускалась: активный AWG на компьютере использует тот же peer, новая параллельная сессия может переназначить получателя на сервере. Телефон выключен. Никаких переключений текущего VPN не выполнялось. Локальный стенд использует собственный тестовый peer.

Собран один кандидат в awg-current/windows-10 и windows-11; предыдущие app/core сохранены в network-send-control-overlay.zip. dist и предыдущие быстрые/Roblox-контроли сохранены. Windows 10 требует живой проверки. Промежуточные файлы очищены после успешных проверок.

Результат: устранена воспроизведённая зависимость приёма от задержанной отправки. Ускорение YouTube и исчезновение пользовательских остановок ещё не подтверждены. Одна итоговая ручная проверка кандидата: то же 4K60, обычное воспроизведение, перемотка, две минуты 2× и Roblox. При ухудшении использовать сохранённый контроль.
