# Windows 10/11 — подписки и журнал, тестовая 1.2.6

## Исправления

- «Обновить» в меню подписки использует отдельное действие, обычный цвет текста и настоящий идентификатор подписки. Название группы не передаётся серверной части вместо ID. Повторное нажатие во время ручной или фоновой загрузки блокируется; после окончания кнопка снова доступна.
- Ручное обновление сообщает об ошибке вместо ложного сообщения об успехе. В сведениях подписки показаны последнее и следующее обновление по местному времени. Отключённое автообновление отображается как отключённое.
- Для профилей, сохранённых старой версией с неизвестным `support-x25519mlkem768` без значения, при загрузке приложения назначается немедленное обновление соответствующей подписки, если автоматическое обновление разрешено её настройками или интервалом сервера. Значение флага не выдумывается и проверка Reality не обходится. До успешной загрузки предлагается обновить подписку или повторно импортировать ссылку. Остальные интервалы и параметры профилей сохраняются.
- Автоматические обновления отмечаются в журнале кодами `SUBSCRIPTION_AUTO_REFRESH_STARTED/COMPLETED/FAILED`, с источником `startup` или `timer`. Фоновая проверка больше не переносит срок параллельного ручного обновления. При неудаче рабочий список сохраняется.
- «Запуск Windows и сон» находится первым разделом внутри вкладки «Подключение», со стандартными переключателями. Сохранение настроек остаётся отдельной кнопкой; автозапуск не включается сам.
- `AWG_FAMILY_DNS_OBSERVATION` — дополнительная проверка семейства IPv6: успех/отсутствие адресов — информация, отказ/таймаут — предупреждение. Это не замена результата основной DNS-проверки.
- `TUN_UDP_NETWORK_REJECTED` при работающем VPN и `REALITY_RELAY_FAILED` с конкретным flow — предупреждения отдельных потоков. Ошибки запуска, готовности и восстановления остаются ошибками. Намеренная блокировка `VISION_UDP443_BLOCKED` отмечается как политика, её настройка не изменена.

## Проверка

455 тестов .NET прошли, включая миграцию старого профиля, сохранение отключённого автообновления, расписание и уровни журнала. DOM-проверки подтвердили передачу ID, блокировку/возврат кнопки, расположение и сохранение переключателей для моделей Windows 10 и 11. Это не визуальная проверка на реальном устройстве и не повторное испытание VPN-соединений.

Сетевые алгоритмы и параметры не менялись. В пакетах сохранены проверенные ядра: Windows 10 — из предыдущей тестовой сборки, Windows 11 — закреплённый baseline. Предыдущие dist, ZIP, Android и пользовательские файлы AppData не заменяются; публикации GitHub нет.

## Как проверить

1. Закрыть текущий ior и распаковать нужный пакет в новую папку.
2. Открыть сведения о подписке: проверить время следующего обновления; вручную нажать «Обновить» и проверить дату/результат.
3. Для старого профиля со спорной отметкой дождаться обновления при запуске. При отсутствии сети или разрешения HWID прежний список остаётся; разрешение предоставляется обычным способом.
4. Проверить «Настройки → Подключение»: раздел запуска/сна расположен сверху. Изменения применяются кнопкой сохранения.
5. Проверить AWG и VLESS. Предупреждение одного потока не означает отключение VPN. Для проверки таймера оставить приложение открытым до установленного срока; приложение не получает мгновенные push-сообщения об изменении серверного конфига.
