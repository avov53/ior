# Тестовая Windows 1.2.7

При подтверждённых метаданных AG Unlocker сообщение о конфликте DNS называет
программу и рекомендует штатно отключить её изменение DNS. Завершение процесса
может оставить правила. Для неизвестного владельца показывается общее сообщение;
при признаках Group Policy/DirectAccess предлагается обратиться к администратору.
Произвольные имена, комментарии и внутренние домены в сообщение не вставляются.

Проверка выполняется только при обнаруженном конфликте ior-core TUN.
Для успешно работающего Xray предупреждение не добавляется. Процессы,
сторонние DNS-правила и маршруты эта правка не изменяет.

400 тестов прошли. Включены проверки подтверждённого/неподтверждённого
AG Unlocker, неизвестного владельца, пустой записи и корпоративной политики.
В пользовательском DNS-отчёте подтверждены две записи AG Unlocker.
Реальный запуск на Windows 10 сотрудника остаётся ручной проверкой.

Распаковать полный Windows 10 ZIP в новую папку, закрыть старую копию ior,
запустить новую и повторить подключение ior-core TUN. Сообщение объясняет
существующий конфликт; не устраняет его автоматически. После штатного
отключения изменения DNS в AG Unlocker повторить подключение и прислать журнал.

Предыдущие пакеты и dist сохранены. Android не менялся, публикации GitHub нет.
