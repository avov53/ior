# Android 0.2.13 — окно импорта и меню подписки

В меню подписки удалён повторный пункт настроек: раньше его добавляли одновременно `menuButtons` и декоратор `sheetView`.

Для окна «Добавить сервер» Android использует один обработчик жестов и Web Animations API для `transform`, без смешивания ручного смещения и Motion. Обновления положения объединяются через `requestAnimationFrame`; вниз окно следует за пальцем без ограничения в 180 px, вверх используется небольшое упругое смещение. Завершение жеста и кнопка закрытия продолжают анимацию из текущего положения до выхода окна за экран. Отмена жеста возвращает окно на место. Заголовок не передаёт жест браузерной прокрутке, содержимое формы продолжает прокручиваться стандартно. Обновления разметки откладываются до конца жеста/анимации. Режим уменьшения анимаций учитывается.

В обработчике диагностических событий уровень журнала читается отдельным методом репозитория. Больше не требуется на каждом опросе сериализовать всё состояние, включая до 2000 строк журнала, и перечислять LAN-интерфейсы.

Приложенный текстовый лог содержит 144 строки примерно за одну секунду. В доступных завершённых соединениях Reality TLS занимает 86–143 мс, подключение 138–204 мс, первый ответ 184–377 мс, DNS 72–94 мс. Есть попадания в кэш DNS адреса сервера. Видимых ошибок/таймаутов нет. `TUN_TCP_IO_WAIT` описывает ожидание чтения и не доказывает задержку воспроизведения. Фрагмент не содержит достаточных данных о скорости, объёмах передачи и моменте загрузки видео для выбора сетевой оптимизации. Нативное ядро и параметры Reality оставлены прежними.

Проверки: 53 Android JUnit; DOM/bridge-проверка, включая единственный пункт настроек подписки, открытие/закрытие, перетаскивание вниз и вверх, объединение перемещений в один кадр, отмену жеста, отсутствие захвата прокрутки формы, обновление состояния во время жеста и закрытие кнопкой. Плавность на физическом телефоне требует ручной проверки.

APK: `android-output/sheet-20261031/ior-android-arm64.apk`, versionCode 15. Предыдущий APK 0.2.12 не заменён. Исходные файлы до изменений сохранены в `.local/backups/android-sheet-20261031`.

Для исследования видео: воспроизвести задержку, нажать «Отметить торможение видео», затем «Экспорт диагностики» и передать полный ZIP. Он содержит подробные счётчики, которых нет в скопированном экранном журнале.
