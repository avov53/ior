# AWG Windows и журнал Android — 2026-10-31

Windows 1.2.5 устраняет остановку запуска с `NATIVE_TUN_UDP_PROBE_ROUTE_INVALID`, когда DNS профиля одновременно используется для bootstrap и имеет обязательный физический маршрут /32. Проверка выбирает другой внешний DNS-адрес только после подтверждения маршрута через конкретный созданный TUN. Если подходящего маршрута нет, запуск не считается успешным. Проверки HTTPS, ответа UDP/DNS и подтверждения PROXY остаются включены. Нативное ядро и параметры AWG не изменены.

Android 0.2.12 (versionCode 14) сохраняет видимый журнал в `noBackupFilesDir/diagnostics/console`. Записи разных протоколов дополняют друг друга, сохраняют контекст сессии и восстанавливаются после повторного запуска. Последние 2000 строк отображаются в интерфейсе; более ранние сохранённые записи доступны в папке `console/` ZIP-экспорта диагностики. События интерфейса также проходят через нативный журнал: прежний обработчик прототипа мог обрезать историю до 200 строк при смене темы и других действиях.

Десятая часть выбранного общего дискового лимита выделяется консольному журналу, остальная часть — подробным сетевым событиям. Срок хранения применяется к обеим частям. Кнопка очистки удаляет обе части. Старые версии приложения не записывали всю консоль на диск, поэтому уже вытесненные строки консоли восстановить невозможно; прежние подробные диагностические файлы продолжают сохраняться по политике хранения.

Проверки: 375 тестов .NET; 53 Android JUnit; проверка Android DOM/bridge, включая сохранение более 300 строк при смене состояния подключения и при событии интерфейса. В Android проверены смена сессии, повторное открытие хранилища, экспорт и ручная очистка. Реальное подключение AWG к пользовательскому серверу и установка APK на телефон здесь не выполнялись.

Новые пакеты:

- `windows-output/awg-journal-20261031/windows-11/ior.exe`
- `windows-output/awg-journal-20261031/windows-10/ior.exe`
- `android-output/awg-journal-20261031/ior-android-arm64.apk`

Windows запускается из полной папки пакета. Предыдущие пакеты сохранены. Копии исходных файлов до изменений находятся в `.local/backups/awg-journal-20261031`.

Ручная проверка: подключить AWG на Windows и убедиться, что проходит проверка HTTPS/UDP; на Android подключить AWG, затем VLESS или Hysteria2, открыть журнал и проверить наличие событий обоих протоколов. После повторного открытия приложения журнал должен восстановиться; экспорт должен содержать `console/` и подробные JSONL-файлы.
