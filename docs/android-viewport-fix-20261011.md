# Android 0.2.1: вкладки и прокрутка

Причина регрессии 0.2.0: после перехода на процентную высоту `.app` контейнер `#mobile` оставался с автоматической высотой. Экран растягивался по содержимому, нижняя навигация уходила за границу WebView, а прокрутка body была отключена.

Исправлена вся цепочка высоты html → body → #mobile → .app. Прокручивается область .content; нижние вкладки остаются внутри доступного нативного контейнера и не скрываются при событии клавиатуры. Отступы системных панелей по-прежнему учитываются только в Android. Сетевой код и Rust-ядро не менялись.

Проверка настоящего CSS layout в изолированном Chromium с 18 тестовыми конфигурациями:

| Версия | Высота экрана | Высота приложения | Вкладки | Прокрутка |
|---|---:|---:|---|---|
| До исправления | 740 / 480 | 2029 | не видны | не работает |
| После | 740 / 480 | 740 / 480 | видны | работает |

Оба результата проверены в тёмной и светлой темах; меньшая высота включает событие клавиатуры. Это браузерная проверка геометрии, не проверка на подключённом телефоне. Тест адаптера UI также прошёл.

Собран подписанный APK версии 0.2.1, versionCode 3; содержимое assets/index.html сверено с исходником, подпись и zipalign проверены. Актуальный пакет находится в distandroid/ior-android-arm64.apk, контрольная сумма — в checksums.sha256. distandroid.bat собирает это исправление. Промежуточные файлы проверки и сборки удаляются после успешного завершения.
