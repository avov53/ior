# Windows 1.2.6 — удаление sing-box из списков

Исправлены реальные входные файлы сборщика интерфейса: prototype.js и
feature-pack.js. Прежнее изменение index.html не устраняло пункт после сборки.
Оба элемента выбора теперь используют поддерживаемый набор хоста и известные
ior-core/xray-core. Удалённое ядро не показывается даже отключённым пунктом.
Старое сохранённое предпочтение sing-box преобразуется в ior-core.

DOM-проверка покрывает главный экран, настройки, старое предпочтение и лишний
отключённый sing-box в тестовом ответе хоста. 438 тестов .NET прошли.
Внутри новых пакетов проверены актуальный HTML, отсутствие sing-box*.exe и
совпадение хешей обоих нативных ядер с предыдущими выбранными пакетами.
Windows 11 baseline закреплён в сборщике, чтобы обычный dist.bat также сохранял
проверенный бинарник. Сетевые алгоритмы этой правкой не меняются.

Исходники направляются в main; релиз и Android не публикуются этой операцией.
Ранее переданный Android 1.2.6/code 22 сохраняется локально. Старые пакеты
удаляются только при очистке, с сохранением текущего dist, новой тестовой сборки
и стабильных ZIP/APK v1.2.5 для возврата.
