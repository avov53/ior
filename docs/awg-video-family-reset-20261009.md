# AWG: сохранить Roblox и убрать IPv6 fallback видео

9 октября 2026. Контроль пользователя с рабочими картинками Roblox и медленным YouTube: dist, ядро 374f38ea114d. Перед правками сохранён roblox-working-control-overlay.zip (ior.exe, ior.dll, core и WebUI для Windows 10/11). Прежние stable-fast-control.zip и seek-fast-control-overlay.zip сохранены. Кандидат: 6768da5b1422.

В журнале пользователя несколько потоков googlevideo имеют исходный IPv6 адрес, затем IPv4 транспорт и прежний TCP-стек. Время ожидания чтения не трактуется как скорость или доказательство зависания. Это подтверждает использование fallback пути, но не устанавливает единственную причину замедления.

Изменение: для AWG TUN, если после анализа имени и обычного выбора маршрута подтверждён PROXY, неподдерживаемая семья назначения больше не переводится в новый IPv4/IPv6 TCP-транспорт. Возвращается AWG_PROXY_ADDRESS_FAMILY_UNSUPPORTED. В Windows TCP-стеке эта конкретная ошибка вызывает явный RST через новый TcpAbortHandle локальной закреплённой копии netstack. Смoltcp получает возможность отправить RST до удаления сокета. Обычный drop и half-close остаются graceful. UDP получает существующую ICMP-ошибку. Известные до SYN маршруты продолжают использовать уже существующий ранний отказ.

Новый отказ действует только при включённой runtime AWG family policy и только для выбранного PROXY. Поддерживаемые IPv4 и dual-stack, DIRECT, REJECT, обычный WireGuard, Hysteria2 и Reality не переключаются на новую политику. Для неоднозначного SYN сохраняется анализ имени; установленное соединение не мигрирует на другой маршрут. Приложение с доступным IPv4 может повторить подключение по прямому пакетному пути. Поведение конкретного браузера после сброса требует ручной проверки.

DNS CNAME+SOA / NODATA backup, кеши, DNS профиля, MTU, окна, алгоритмы перегрузки, AWG-движок и параметры шифрования/обфускации не менялись. Не добавлялись статические адреса, специальные обходы сайтов или скрытый DIRECT. Новое событие AWG_PROXY_FAMILY_REJECTED отделяет намеренный отказ семьи от передачи; TUN_TCP_FAMILY_RESET подтверждает запрос RST.

Проверки: native_router 13 (новый отказ для TCP/SNI/UDP, REJECT, поддерживаемый IPv4 и реальный loopback IPv6 DIRECT), tun_dns 15, tun 2, tun_reject 2, AWG 17 (группы пересекаются); netstack regression 2 с виртуальным SYN/SYN-ACK/ACK и проверкой RST при abort, FIN при обычном drop. Отдельно прошли half-close / отмена / бюджеты (6 проверок). 7 расширенных AWG-стендов и browser automation не запускались. Rust release и Windows 10/11 publish прошли. Живая Windows 10 проверка, загрузка больших файлов через реальный AWG/Wintun и пользовательская скорость кандидата пока не подтверждены.

Ручная проверка: закрыть старый ior, запустить windows-11/ior.exe (или windows-10) отсюда, проверить в отчёте сборку 6768da5b1422. С тем же профилем и маршрутизацией открыть Roblox, затем одно и то же видео 4K: запуск, перемотка и минимум две минуты на 2x. Три одинаковых сравнения контроля и кандидата; фиксировать остановки, Buffer Health и Dropped Frames. Не считать отсутствие fallback достаточным доказательством ускорения. Кандидат принимать только при сохранении картинок Roblox и восстановлении скорости видео.

Текущее пользовательское VPN не отключалось. dist не запускался и не изменялся. Для отката закрыть приложение и извлечь roblox-working-control-overlay.zip поверх соответствующих windows-10/windows-11 каталогов кандидата, сохранив остальные runtime-файлы. Краткие контрольные суммы находятся в validation.json и control manifests. Подробные успешные журналы и проверенные промежуточные сборочные кеши очищаются после выдачи.
