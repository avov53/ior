# Roblox: DNS при проверке IP-правил

9 октября 2026. Текущее соединение пользователя Hysteria2 не остановлено.

Через работающий локальный proxy API thumbnails.roblox.com вернул HTTP 200 и публичный адрес картинки tr.rbxcdn.com. Получение картинки завершилось HttpRequestException; точная причина этого живого отказа ещё не подтверждена.

В общем маршрутизаторе найден дополнительный путь разрешения имени через физический bootstrap до выбора маршрута при наличии IP-правил. Для runtime с настроенным DNS разрешение теперь использует DNS-маршрут, resolver профиля и ограниченный кеш. PROXY-запрос не зависит от физического bootstrap. DIRECT и REJECT сохраняются; IP-правила проверяются после разрешения адреса. Усечённый UDP-ответ повторяется по DNS/TCP. Параметры транспортов и быстрого AWG не изменены.

Целевой тест воспроизводит недоступный bootstrap и подтверждает разрешение через PROXY; отдельная проверка подтверждает, что IP REJECT остаётся обязательным. Прошли 12 тестов native_router, 13 tun_dns, 2 tun и 16 AWG (группы пересекаются; 7 стендовых тестов AWG не запускались). Release-сборка и публикации Windows 10/11 успешны.

Кандидаты находятся в verification-publish/awg-current/windows-10 и windows-11. Контрольные архивы stable-fast-control.zip и seek-fast-control-overlay.zip сохранены. dist не изменён.

Статус: устранён воспроизводимый дефект разрешения имени. Исправление всех картинок Roblox, включая 2D изображения внутри игр, ещё не подтверждено. Живая проверка Windows 10 и последовательное сравнение AWG Rust/Go не выполнялись. Кандидат не заменяет уже запущенный процесс; проверять после переподключения, когда пользователь будет готов.
