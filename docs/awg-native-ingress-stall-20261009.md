# AWG: блокировка общего приёма одним медленным потоком

9 октября 2026. Контроль пользователя 451ce1740d01 сохранён в transfer-stall-control-overlay.zip. Прежние быстрые/Roblox-контроли сохранены. Кандидат: 5675a955181e. dist и действующее соединение не изменены.

На старом коде воспроизведена конкретная ошибка: PacketSender.deliver_native ожидал sender.reserve в общем цикле Rust AWG, когда очередь raw-потока заполнена. Этот же цикл читает следующие UDP-пакеты, отправляет исходящие сообщения и обслуживает таймеры. Локальный тест остановленного читателя блокировал доставку соседнему потоку и падал за 100 мс. Эта ошибка не требует увеличения счётчика потерь, поскольку ожидание возникало до выделения пакета. Её связь с конкретным зависанием YouTube пока не подтверждена пользовательским отчётом.

Исправление: нативный AWG передаёт пакеты в отдельную FIFO доставки потока и не ждёт его потребителя в общем crypto/timer loop. При свободном выходе остаётся быстрый try-reserve путь без фонового worker. Worker создаётся только при давлении; затем все новые пакеты этого потока идут через тот же FIFO до закрытия, чтобы не обгонять уже сохранённые пакеты. Queue capacity 2048 пакетов на поток; storage списывается с существующего общего packet budget 64 МиБ. Полная очередь и исчерпание бюджета имеют явные счётчики; бесконечных очередей нет. Отмена последнего владельца останавливает worker и освобождает накопленные пакеты. Fallback Rust AWG также использует это ограниченное хранение. Raw-маркер для ICMP/NAT остаётся отдельным: новое budget accounting не меняет классификацию пакетов.

Go dispatch не переключён на новый FIFO, WireGuard/Hysteria2/Reality пути не менялись. Входящие данные Rust AWG сохраняют порядок. Не менялись MTU, окна (AWG fallback остаётся 2 МиБ с меньшими размерами при исчерпании прежнего дополнительного receive budget), DNS/CNAME+SOA, маршруты, rekey параметры, криптография и сервер. Соединения не сбрасываются ради повторной попытки и не перемещаются между стеками.

Проверки: регрессия slow reader до/после (старый код fails, новый passes), соседний поток получает данные при остановленном читателе, 128 пакетов доставлены FIFO без повреждения, отмена возвращает весь packet storage. Отдельно queue-pressure тест проверяет ограничение бюджета, счётчик overflow, доступность соседнего получателя и освобождение памяти. Прошли tunnel_outbound 6, packet budget 2, receive budget 2; routing 13, DNS 15, packet routing 6 проверены в этой работе (группы пересекаются). Локальный Rust AWG против официального Go тестового сервера с синтетическими ключами: 64 МиБ + 8 маленьких запросов, отмена, пауза и новый запрос. Целостность подтверждена; 64 МиБ 16,639890 с, повтор 1 МиБ 0,984690 с; queue/budget drops в этом прогоне 0. Время не является сравнением производительности YouTube. .NET launch/report tests 9 passed. Release и Windows 10/11 publish успешны.

Диагностический старт раньше опирался только на окружение. Добавлен явный --resource-diagnostics=domain,domain: приложение после запуска устанавливает процессный selector перед созданием ядра. Он не сохраняется в state и не действует при обычном запуске. Принимаются 1–8 DNS-доменов, отвергаются URL, IP, пустые/длинные значения. Cmd/PowerShell launchers дополнительно передают аргумент, не полагаясь на наследование окружения при повышении прав. resources.jsonl остаётся ограниченным 256 КиБ на запуск, без signed URLs, cookies и содержимого запросов.

Статус: устранена воспроизведённая блокировка между потоками, но фактический видеопоток пользователя ещё не сопоставлен с ней. На момент работы resources.jsonl отсутствовал. Реальное последовательное сравнение Rust/Go на профиле пользователя и воспроизведение Firefox не выполнялись: текущий VPN не отключался. Старое 451-соединение продолжает работать до ручного закрытия приложения. Не заявляется устранение всех остановок или внешнего ограничения CDN.
