# AWG с маршрутизацией: адресные наблюдения и TCP fallback — 2026-10-09

В пользовательском фрагменте поток 441 к rr5---sn-aj5goc-5j.googlevideo.com
принят как IPv6, после TLS-имени переведён на IPv4 через прежний TCP-стек с
окном 128 КиБ. Зарегистрирован 101 fallback; очереди и бюджет не переполнены.
Фрагмент не позволяет установить, откуда браузер получил IPv6: кеш, DoH или
предыдущая сессия. Зависание YouTube в локальном браузере не воспроизводилось.

## Изменения

- Блок «Маршрутизация AmneziaWG» полностью удалён из дополнительных настроек.
  Правила выбираются во вкладке маршрутизации, Rust остаётся основным.
- Найден и исправлен отдельный кеш наблюдений: транспортные DNS-запросы после
  TLS-определения имени теперь пополняют ту же ограниченную таблицу, что и DNS TUN.
  Обычный WireGuard и остальные протоколы сохраняют прежнюю DNS-политику.
- Для PROXY IPv4-only AWG запускается фоновое получение реальных AAAA по DNS
  профиля. Повод — A/AAAA/HTTPS/SVCB-запрос или определённое TLS-имя IPv6-потока.
  Ответ приложению не задерживается и не переписывается; Windows IPv6 сохраняется.
  Если resolver подтверждает тот же адрес и все наблюдаемые имена выбирают PROXY,
  следующие новые IPv6-соединения получают ранний отказ, позволяющий выбрать IPv4.
  Уже открытые соединения не переключаются. DIRECT/REJECT и неоднозначные адреса
  не обходятся. При отличающемся ответе resolver старый IPv6 может остаться неизвестным.
- Максимум четыре фоновые задачи, 128 имён в минутном ограничителе, один запрос
  имени не чаще раза в минуту, общий таймаут 4 с, резервный resolver через 150 мс.
  TC обрабатывается через TCP; проигравшие запросы и задачи при остановке отменяются.
- После проверки включено окно 512 КиБ только для fallback TCP AWG. Передающее
  окно 128 КиБ, дополнительная память ограничена 64 МиБ на сессию; при исчерпании
  остаётся 128 КиБ. Разрешение возвращается при закрытии/отмене. Nagle уже отключён;
  ACK delay, управление перегрузкой, профильный MTU/DNS/обфускация не менялись.
- Журнал показывает фактические параметры fallback, результат семейной DNS-пробы
  и число DNS-имён при fallback. Ключи и содержимое запросов не журналируются.

## Проверки

- 14 целевых AWG-проверок; 12 проверок DNS (одна пересекается с AWG-набором),
  две проверки бюджета и одна локальная WireGuard TCP/UDP-проверка прошли.
  Проверены общий кеш, отсутствие задержки NODATA, предел/дедупликация/отмена проб,
  ранний IPv6-отказ и сохранение DIRECT при конфликтующем имени общего адреса.
- Контролируемый Rust AWG → официальный Go: RTT 100 мс, фиксированные потери
  0,5%, три чередующихся повтора на окно, по 8 МиБ с проверкой целостности и
  параллельно 20 маленьких запросов. Медианы загрузки: 128 КиБ 10,778484 с,
  512 КиБ 6,503313 с (сокращение 39,7%). p95 маленьких запросов: 125139 → 123196 мкс.
  Критерии ≥15% и отсутствие ухудшения p95 >5% выполнены. Это локальный стековый
  стенд, не TCP Windows, не YouTube и не измерение скорости внешнего сервера.
- React, release Rust и self-contained Windows 10/11 publish прошли. Общие
  .NET-тесты повторно не запускались: C# затронут только удалением поля снимка UI.
- Системные маршруты/Wintun, пользовательский VPN и сервер в проверках не менялись.
  Живая Windows 10 и браузер требуют ручной проверки. Firefox не автоматизировался.

## Сравнение и откат

Кандидат находится в awg-current/windows-11 и windows-10. Запускать полный каталог,
переподключить VPN. На том же профиле проверить пять запусков/перемоток и длительное
4K на 2×, затем изображения и Discord. Записать время остановок, Buffer Health,
Dropped Frames и журнал. Ждать AWG_FALLBACK_TCP_PARAMETERS receiveBytes=524288;
AWG_FAMILY_DNS_OBSERVATION recorded — получение доказательства, а не гарантия отказа
всем IPv6. Для пакетного PROXY — AWG_PACKET_ADMITTED; неизвестное имя может остаться fallback.

control-overlay.zip (~6,6 МиБ) содержит изменяемые файлы предыдущего рабочего
кандидата. Для контроля/отката закрыть ior, скопировать полный текущий пакет в
отдельное место и распаковать поверх него overlay. Общие зависимости не менялись.
Оригинальный кандидат сохранить; архив применим к Windows 10/11 из этой серии.

Готовые пакеты, один контрольный overlay, отчёт и контрольные суммы остаются в
awg-current. Созданные промежуточные файлы и сборочные кеши удалены. dist и
исторические пакеты сохранены. Ускорение YouTube и устранение пользовательского
зависания остаются неподтверждёнными до ручного сравнения.
