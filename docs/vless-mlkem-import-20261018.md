# Android 0.2.7: импорт support-x25519mlkem768

Причина сообщения «Не поддержан параметр VLESS · 0»: параметр ссылки
`support-x25519mlkem768=true` отсутствовал в списке разрешённых. `· 0` —
количество серверов в подписке, а не значение параметра.

Импорт теперь принимает `true`/`1` для Reality с fingerprint chrome/firefox
(включая chrome по умолчанию). В нативном ядре эти профили уже используют
провайдер с X25519MLKEM768; криптография и проверка Reality не изменены.
Ссылка сохраняется целиком. Настройка из Clash reality-opts передаётся в ту же
проверку. Неверные значения, явное отключение и Safari с этим флагом отклоняются
с отдельным сообщением: они требуют других настроек провайдера и не должны
молча игнорироваться.

Исходные файлы перед изменениями: `.local/backups/vless-mlkem-import-20261018`.
Предыдущие APK в distandroid и android-output/vless-resume-20261018 сохраняются.
Регрессионные тесты используют вымышленные адреса и UUID, без данных пользователя.

Документация параметра:
https://github.com/MetaCubeX/Meta-Docs/blob/main/docs/config/proxies/tls.en.md

После установки нового APK обновить подписку. Подключение и скорость на телефоне
проверяются отдельно; тесты импорта не подтверждают доступность сервера.

Проверки: 37 Android JUnit-тестов прошли, проверка интерфейса прошла, Rust release
и Android release собраны. Подпись APK проверена и совпадает с кандидатом 0.2.6;
проверка zipalign с размером страницы 16 КиБ прошла. Скрипты сборки и тестов
теперь задают ANDROID_USER_HOME внутри .local/android-tools/android-user.
