# AWG: возврат последнего принятого быстрого варианта

В awg-current/windows-11 и windows-10 восстановлен улучшенный контроль, для которого
пользователь подтвердил быструю перемотку, запуск 4K и 2×. Использованы полный
stable-fast-control.zip и seek-fast-control-overlay.zip; Windows 10 дополнен
сохранёнными sing-box.exe и ior.win10. Все файлы из контрольного manifest совпадают
по SHA256: это архивные пакеты, а не новый кандидат с похожими настройками.

Ядро: 455b2b3187c26cb0ae5134c11058c303f428b42dd4271898444ea921641224c2.
Архивы контролей сохранены. dist, APPDATA/профили, исходники других задач и
исторические пакеты не заменялись. Текущие диагностические Windows-пакеты в
заменяемом awg-current заменены контролем с предварительной проверкой временной копии.

Из рабочего кода удалены только добавленные последней итерацией наблюдение rekey,
периодические отчёты сессии, определение причины промаха кеша и соответствующая
передача дополнительных полей через C#. Сохранены Rust, исправленная маршрутизация,
семейные DNS-наблюдения, общий кеш ответов, буфер 512 КиБ и бюджет 64 МиБ.
Тестовый длительный стенд сохранён для дальнейшей работы, он не входит в release.

16 целевых AWG-тестов и две .NET-проверки диагностики прошли. Восстановленный
источник release собирается; его отпечаток отличается от старого архива, поэтому
пользовательские пакеты и сохранённый release executable взяты именно из контроля.
Длительный стенд и большие матрицы повторно не запускались. Браузер после отката
и живая Windows 10 в этой итерации не проверены.

Полностью закрыть прежний ior, запускать ior.exe из полного каталога Windows-пакета,
переподключить AWG. При вручную заданном пути ior-core проверить префикс сборки
455b2b3187c2. На том же ролике/качестве/сервере/маршруте проверить запуск, перемотку
сразу и спустя две минуты, 2×. Если точный контроль тоже медленный, это не доказывает
регрессию диагностики: сравнить внешний маршрут/CDN и условия загрузки браузера.
Использовать время замедления и новый журнал для следующего отдельного исправления.

Статус: точный быстрый контроль восстановлен. Возврат пользовательской скорости
в текущих сетевых условиях требует ручного подтверждения; мгновенная загрузка
не гарантируется. Предположительных новых оптимизаций в восстановленный пакет нет.
Промежуточные копии и сборочные кеши работы очищены; контрольные суммы сохранены.
