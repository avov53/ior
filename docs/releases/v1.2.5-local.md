# Windows 1.2.5 — локальная проверка, 2026-11-05

На GitHub не опубликовано. Android и macOS не изменялись.

## Причина и исправление

В приложенном журнале Windows 1.2.4 импорт подписки проходит, но подключение
останавливается до запуска ядра: `Неподдерживаемый параметр: support-x25519mlkem768`.
Windows-парсер теперь сохраняет значение этого параметра и принимает true/1
для VLESS Reality с fingerprint chrome/firefox (chrome по умолчанию), как Android.
Другие значения и сочетания отклоняются. Rust-ядро и проверка сертификатов не менялись:
существующий провайдер Reality уже поддерживает этот обмен ключами.

После установки обновить подписку. В ранее сохранённом профиле 1.2.4 осталось
только имя неизвестного параметра, его исходное значение восстановить невозможно.
Профили без этого параметра продолжают использовать прежнее поведение.

Sing-box исключён из обоих элементов выбора ядра и заблокирован для нового
подключения. Сохранённый выбор sing-box/неизвестного ядра при загрузке настроек
и восстановлении резервной копии заменяется ior-core. Внутренние файлы и код
sing-box сохранены для совместимости; сетевые механизмы Xray/AWG не переписаны.

## Результаты проверок

- 392 теста .NET прошли; отдельно проверены допустимые/недопустимые параметры,
  сохранение модели профиля, список ядер и политика обновления 1.2.4 → 1.2.5.
- Проверка DOM/моста интерфейса прошла; визуальная плавность не измерялась.
- Собраны Windows 10/11: `windows-output/release-v1.2.5-20261105/windows-10`
  и `windows-11`. Управляемая версия 1.2.5.0; ядро da0aeba36215 прежнее.
- Установщик проверен на путях с пробелами/кириллицей: успех и возврат файлов
  при занятом файле, сохранение пользовательских данных.
- На отдельных полных копиях пакетов 1.2.4 обеих платформ выполнена установка
  1.2.5 без запуска приложения (`NoLaunch`). Сверены все 531 файла каждого пакета,
  версия DLL стала 1.2.5.0, добавленный пользовательский файл сохранён.
- Загрузка релиза с GitHub, окно обновления и перезапуск для 1.2.5 пока не проверялись:
  публикация запрещена до пользовательской проверки. Реальное VPN-подключение
  к серверу пользователя также требует ручной проверки.

## Возврат

Исходники до правки и контрольные суммы находятся в
`.local/backups/windows-1.2.5-20261105`. Полные прежние сборки 1.2.4 остаются
в `windows-output/release-v1.2.4-20261104`, их контрольные суммы сохранены
в `working-1.2.4-checksums.json` резервной папки. Текущий `dist` не заменялся.
