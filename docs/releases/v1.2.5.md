# ior v1.2.5

- Windows: исправлен импорт параметра support-x25519mlkem768 для VLESS + Reality с chrome/firefox. После установки обновите подписку перед подключением.
- Windows: sing-box убран из выбора ядер; прежний выбор переводится на ior-core. Доступен также xray-core.
- Android: версия 1.2.5, versionCode 21, прежняя подпись; функциональность не менялась.

## Скачать

Windows 10: ior-windows-10.zip. Windows 11: ior-windows-11.zip. Распакуйте полный архив.
Android ARM64: ior-android-arm64.apk; установите поверх прежней версии. Автоматического уведомления об обновлении Android пока нет.

## Проверки обновления Windows

Версия 1.2.5 распознаётся как обновление для 1.2.4. На изолированных копиях полных пакетов Windows 10/11 выполнена установка 1.2.4 → 1.2.5: сверены все 531 файла каждого пакета, пользовательский файл сохранён. Проверены возврат файлов при ошибке записи и пути с кириллицей/пробелами.

Эти проверки выполнялись без запуска приложения (NoLaunch): повторный реальный перезапуск и полный пользовательский сценарий обновления через GitHub для данного релиза не проверялись. Подключение Windows проверено пользователем перед публикацией. Локальные тестовые версии выше 1.2.5 не получат этот релиз как обновление.

Исходники и предыдущие релизы сохранены. Контрольные суммы — SHA256SUMS.txt.
