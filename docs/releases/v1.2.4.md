# ior v1.2.4

Android (arm64) и Windows 10/11.

- Поддержка Hysteria2 + Salamander в собственном ядре, без отключения проверки сертификатов.
- Ошибочная ссылка в текстовой подписке не блокирует остальные поддерживаемые записи.
- Переключатель маршрутизации, автоматический выбор маршрута подписки и расширенный журнал.
- Новая прозрачная иконка приложения; локальные значки отслеживаемых сервисов.
- Windows: предложение обновления, проверка версии пакета, резервная копия и откат при ошибке установки.

## Установка

Windows: скачать ZIP своей системы и распаковать всю папку. Android: установить APK поверх прежней версии, без удаления приложения; настройки и подписки сохраняются. Для Android автоматическое обновление из GitHub пока не реализовано.

## Обновление Windows

Версия 1.2.4 новее опубликованной 1.2.3. В 1.2.3 используется прежний механизм: если окно не появилось, выполните ручную проверку обновлений. Новое окно и новый PowerShell-установщик начнут работать после установки 1.2.4. Ограничения старого cmd-установщика, включая пути с кириллицей, нельзя исправить задним числом. При ошибке старого механизма закройте ior и распакуйте новый ZIP в прежнюю папку с заменой файлов; пользовательские данные не удаляйте.

Пользователям тестовой Windows 1.2.11 релиз 1.2.4 автоматически не предлагается: это меньший номер. При необходимости установите публичную версию вручную.

## Проверки

385 тестов .NET, 57 Android JUnit. Установка обоих полных Windows-пакетов проверена на изолированных копиях: 531 файл, контрольные суммы совпали, настройки сохранены. Проверены ошибка занятого файла, откат, пути с пробелами и кириллицей. Исходники опубликованы в main. Реальный перезапуск старой версии требует подтверждения UAC и отдельно не считается пройденным до такого подтверждения.

macOS в исходниках остаётся предварительной оболочкой без рабочего VPN; в этот релиз Mac-пакеты не включены.
