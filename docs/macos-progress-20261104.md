# macOS: состояние переноса

Реализован первый этап, полный утверждённый план ещё не завершён.

## Добавлено

- Отдельный проект Tauri 2 с фиксированными версиями и Cargo.lock; системный WebView показывает существующий интерфейс в режиме просмотра.
- Команда состояния явно возвращает vpnAvailable=false. Пустая оболочка не запускает VPN и не требует прав администратора.
- Workflow для arm64 и x64: проверка коммита, сборка Rust-ядра и оболочки, ad-hoc подпись, ZIP, версия, SHA исходников, контрольные суммы.
- GitHub CLI сценарий: проверка чистых отправленных исходников, уникальный запрос, выбор именно соответствующего запуска, ожидание, повторное скачивание по RunId, проверка SHA пакетов.
- dist.bat вызывает общий PowerShell-сценарий. Windows и Mac собираются во временном каталоге; старый dist переносится в резервную папку только после успеха всех этапов. Автоматического push или публикации релиза нет.

## Ещё не реализовано

Адаптер команд интерфейса macOS, хранилище и Keychain, подписки и маршруты, привилегированный помощник, utun, DNS и маршруты, готовность соединения, восстановление сети и сна, диагностический журнал. Поэтому текущий проект НЕ является рабочим VPN для Mac. Никакой готовый Mac-пакет локально не выпущен.

## Проверено локально

Создан Cargo.lock через crates.io. PowerShell-сценарии разобраны синтаксическим анализатором. Генерация macOS HTML и существующие Windows DOM/bridge проверки прошли. Контрольные суммы предыдущих Windows ZIP и Android APK не изменились. Резервная копия прежнего dist.bat и контрольные суммы лежат в .local/backups/macos-20261104.

## Внешние ограничения

GitHub CLI отсутствует. Workflow пока не отправлен в GitHub и не запускался. Сборка ядра и Tauri на macOS не проверена. Проверка сетевого помощника требует изолированного Mac; GitHub-hosted runner нельзя использовать для изменения рабочих маршрутов. Подписи Developer ID и notarization нет.

Следующий этап — macOS CI-компиляция ядра, затем адаптер приложения и защищённый сетевой помощник. Первый запуск Actions может выявить ошибки переносимости; успешный workflow сам по себе не доказывает работоспособность VPN.
